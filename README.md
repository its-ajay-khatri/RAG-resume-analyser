This is an RAG Usecase for resume analyser, simply upload the resume in pdf/image format, and it will analyse your resume on the basis of your skiils it will suggest you the best roles you fit for

to setup frontend, simply follow these steps
1) cd frontend
2) npm install              //to install required packages
3) npm run dev              //run frontend

to setup backend, simply follow these steps
1) cd backend
2) pip install -r "requirements.txt"
3) uvicorn main:app --reload
